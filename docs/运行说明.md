# 本地运行说明（Windows）

## 目录约定

```
data/20261010/*.cor     <- 原始数据，按测量日期分文件夹
scripts/*.py            <- 代码
metadata/*.csv          <- 元数据（填浓度）
out/20261010/           <- 输出，和输入日期同名
```

脚本会自动找 `data/` 下**最新的日期文件夹**，输出到 `out/<同名日期>/`。

## 1. 装 Python

https://www.python.org/downloads/ 下 3.11 或更高，**安装时勾选 "Add python.exe to PATH"**。

```
python --version
```

## 2. 双击 run_all.bat

自动建 `.venv`、装依赖、跑主流程。第一次几分钟，之后很快。

## 3. 手动跑

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

```
:: 主流程
python scripts/dpv_pipeline.py

:: 指定日期
python scripts/dpv_pipeline.py --data 20261010

:: 指定输出目录
python scripts/dpv_pipeline.py --data 20261010 --out out/my_run
```

产物在 `out\20261010\`：

| 文件 | 内容 |
|---|---|
| `dpv_long.csv` | 2000 行长表，每个扫描点一行（画图用） |
| `dpv_features.csv` | 25 行，每条曲线一行，含峰高/峰位/峰宽/Q 等 |
| `report.json` | ANOVA、Tukey、PCA、LOEO 交叉验证全部结果 |
| `figures\fig1..fig6` | 发表级图 |

## 4. 跑校准（要先填浓度）

```
copy metadata\sample_metadata_template.csv metadata\metadata.csv
```

用 Excel 打开 `metadata\metadata.csv`，**必填 `concentration_M` 列**：

- 单位 **mol/L**，写成 `1e-9` 这种科学计数法
- **空白填 0**（这是算 LOD 用的 3σ）
- **不参与分析的行留空**（脚本会自动跳过）
- 别存成 `.xlsx`，只读 CSV

然后：

```
:: 比值法（推荐）
python scripts/ratiometric_calibration.py --meta metadata/metadata.csv

:: 单峰校准曲线
python scripts/calibration.py --meta metadata/metadata.csv
```

或者双击 `run_calibration.bat`。

比值法需要**至少 3 条空白**才能算 LOD。没有空白它会直接告诉你算不了，
而不是编一个数字出来。

## 5. 常见问题

**中文文件名乱码 / UnicodeEncodeError**
脚本已经把 stdout 强制成 UTF-8。如果还报错，先执行 `chcp 65001`。

**matplotlib 图里中文变方框**
所有图的标签都是英文，正常不会出现。如果自己加了中文标签：

```python
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False
```

**找不到 .cor 文件**

```
no .cor files found.
Expected data/<date>/*.cor, e.g. data/20261010/.
Point somewhere else with:  --data <folder>
```

检查 `data\` 下是不是有日期文件夹。

**pandas / numpy 版本报错**
用 `requirements.txt` 里的下限版本，很老的 pandas 1.x 也能跑。

**LOD 算出来是 1e+02 M 这种离谱数字**
老版本的问题，已修复。现在 LOD 由空白 3.3σ 反算，超出校准范围会直接报错。

## 6. 脚本之间什么关系

```
scripts/dpv_pipeline.py          核心库 + 主流程
   ├─ parse_cor / resample / baseline_envelope / extract_features
   ├─ auto_data_dir / default_out_dir
   ├─ calibration.py              导入上面的函数，做校准曲线 + PLS
   └─ ratiometric_calibration.py  导入上面的函数，做比值法 + LOD/LOQ
```

三个脚本必须在同一个目录（`scripts/`），因为后两个 `import dpv_pipeline`。
