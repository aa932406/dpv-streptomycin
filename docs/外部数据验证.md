# 外部数据验证：miralab-ai/biosensors-AI

> 目的：用户问「能不能用这个公开数据集来验证 / 训练我们现在的模型」。
> 结论先说：**能用，而且应该用 —— 但用法和我们自己的数据不一样。**

数据来源：<https://github.com/miralab-ai/biosensors-AI>（MIT 许可）
论文：Yeke et al., *A machine learning framework for advanced analytical detection of CD36 using immunosensors below limit of detection*, Biosensors and Bioelectronics: X (2026), doi 10.1016/j.biosx.2025.100733

---

## 1. 它是什么

| 项目 | 内容 |
|---|---|
| 分析物 | CD36 蛋白（不是链霉素） |
| 传感器 | anti-CD36 抗体 / 聚多巴胺修饰丝网印刷碳电极 |
| 数据 | 60 条 DPV 曲线 = 12 个浓度 × 5 次重复 |
| 浓度 | 0、0.005、0.010、0.025、0.035、0.050、1、5、10、15、20、25 ng/mL |
| 电位栅格 | 全部共用，239 点，−0.400 → +0.798 V，步长 5 mV |
| 文件 | `data/lab_measurements/<level>/<rep>.xlsx`，单 sheet，两段并排：列 0-1 是 DPV，列 2-3 是 CV |

**关键细节：`0 ng` 那 5 个文件叫 `bare_1..5`，是裸电极**，不是「加了空白基质的同一支传感器」。
裸电极电流 39.23 ± 0.21 µA（CV 0.5%），和所有修饰过的电极差着十万八千里。
把它当「零浓度」放进模型，等于白送一个类别。

## 2. 信号长什么样（+0.15 V 处电流）

| 浓度 (ng/mL) | 均值 (µA) | SD | CV |
|---|---|---|---|
| 0（裸电极） | 39.23 | 0.21 | 0.5% |
| 0.005 | 34.43 | 4.48 | 13.0% |
| 0.010 | 32.34 | 2.87 | 8.9% |
| 0.025 | 37.66 | 1.16 | 3.1% |
| 0.035 | 30.05 | 6.10 | 20.3% |
| 0.050 | 28.54 | 4.34 | 15.2% |
| 1 | 31.23 | 3.22 | 10.3% |
| 5 | 30.68 | 2.38 | 7.8% |
| 10 | 27.00 | 1.07 | 4.0% |
| 15 | 22.46 | 0.93 | 4.1% |
| 20 | 18.61 | 0.55 | 2.9% |
| 25 | 12.05 | 0.92 | 7.7% |

读三件事：

1. **10 ng 以上是干净的信号关闭型响应**（27 → 12 µA，CV 3–8%）。
2. **1 ng 以下不单调**：0.025 ng 的电流（37.66）比 0.005 ng（34.43）还高，0.035 ng 又掉到 30.05。
   物理上不该这样 —— 说明这个区间里电极之间的差异大于浓度差异。
3. 0–0.05 ng 六组做单因素 ANOVA：**F = 6.20，p = 0.0008** —— 统计上确实有差别，但差别不是单调的。

## 3. 三种验证协议，同一批 60 条曲线

论文用的是 `train_test_split(X, y, test_size=0.2, random_state=40, stratify=y)`：
**按行随机切**，y 是类别编号 0–11。这意味着每条测试曲线在训练集里都有 4 条同浓度的「兄弟」。
它回答的是「能不能认出你已经测过的那个浓度」，不是「能不能测一个没见过的样品」。

我们把三种口径都跑一遍（脚本 `scripts/validate_external.py`）：

| 协议 | 切法 | 训练集里还有同浓度吗 | 最佳 R² |
|---|---|---|---|
| P1 论文口径 | 随机 80/20 | **有**（4 条） | **0.9930** |
| P2 留一重复 | 60 折 | **有**（4 条） | 0.981（曲线）/ **0.990（手工特征）** |
| P3 留一浓度 | 12 折 | **没有** | 0.842（曲线）/ **0.9825（手工特征）** |

P1 复现成功：我们跑出 0.9930，论文报 >0.99 —— 说明代码没跑错，**差别只在切法**。

P2 详细（留一重复，55 折有效）：

| 模型 | 整条曲线 (239 点) | 手工特征 (13 个) |
|---|---|---|
| SVR-RBF | R² 0.981，RPD 7.32 | **R² 0.990，RPD 10.21** |
| 高斯过程 | R² 0.973，RPD 6.18 | R² 0.991，RPD 10.42 |
| 岭回归 | R² 0.824，RPD 2.40 | R² 0.808，RPD 2.31 |
| PLS | R² 0.801，RPD 2.26 | R² 0.795，RPD 2.23 |
| 线性回归 | R² 0.772，RPD 2.11 | R² 0.670，RPD 1.76 |

P3 详细（留一浓度，11 折）：

| 模型 | 整条曲线 | 手工特征 |
|---|---|---|
| SVR-RBF | R² 0.842，3.58× | **R² 0.9825，1.53×，RPD 7.64** |
| 高斯过程 | R² 0.832，3.73× | R² 0.951，2.04×，RPD 4.55 |
| 岭回归 | R² 0.593，7.74× | R² 0.597，7.65× |
| 线性回归 | R² 0.279，15.2× | R² 0.291，14.9× |

置换检验（打乱 60 条曲线之间的浓度标签，60 轮）：
实测 R² 0.9902，零分布均值 −0.40、95% 分位 −0.11、最大 0.009，**p = 0.016**。
→ 这个信号是真的，不是噪声凑出来的。

## 4. 低浓度区（论文声称的 sub-LOD）单独看

| 问题 | 结果 |
|---|---|
| 五个非零低浓度能不能分类（留一重复，5 类） | LDA 84%，随机森林 **88%**（瞎猜 20%） |
| 同样五个浓度，留一**浓度**做回归 | 曲线 R² 0.208，手工特征 **R² 0.741，RPD 2.01** |
| 两两效应量（+0.15 V 电流，Cohen d） | 0.005 vs 0.010 = 0.55；0.035 vs 0.050 = 0.29；**0.005 vs 0.025 = −0.99（方向反了）** |

读法：

- **能认出「这是我已经测过的哪一个浓度」**（88%），因为每个浓度的曲线形状有自己的指纹；
- **不能按浓度排序**（留一浓度 R² 0.74，且 0.025 > 0.005 > 0.010 这种顺序本身是错的）；
- 所以论文「sub-LOD 定量」这个说法要打折：它证明的是**指纹可重复**，不是**剂量-响应可定量**。

## 5. 我们的工具能不能吃它 —— 已经吃了

`scripts/import_external.py` 把 60 个 xlsx 转成项目内部统一的 `.cor` 文本 + `metadata.csv`，
放在 `data/cd36_ngml/`（60 个文件，5 个工作日以外的第 16 个文件夹）。

实测（`dump_ui_json.prepare` → `_regression_block`，和我们界面上「预测」页同一条路径）：

```
n_curves=60  n_points=240  metric=anodic_H  errors=0
window 0.798 .. -0.400 V
12 groups（每个浓度一组）
n_std=55 levels=11 elec=55 batches=1
```

「预测」页跑出的 20 个模型（10 模型 × 2 输入），最佳几行：

| 模型 | 输入 | R² | 误差倍数 | RPD |
|---|---|---|---|---|
| 随机森林 | 整条曲线 | 0.9924 | 1.32× | 11.55 |
| 梯度提升 | 整条曲线 | 0.9781 | 1.61× | 6.83 |
| 高斯过程 | 整条曲线 | 0.9740 | 1.68× | 6.26 |
| XGBoost | 整条曲线 | 0.9725 | 1.70× | 6.09 |
| SVR-RBF | 整条曲线 | 0.9708 | 1.73× | 5.91 |

也就是说：**我们的代码不需要改就能跑别人的数据**，出来的数字和论文同一量级。

顺带修掉一个真问题：这个数据集没有我们 −0.34 V 的 MB 峰，`I_MB` / `ratio` 整列是 NaN。
旧代码「只要有一列 NaN 就把整行丢掉」→ 会把 60 条全丢光、报「0 条标准点」。
现在 `ml_models._clean()` 改成**丢整列、其余中位数补齐**，外部数据才能进模型。

## 6. 结论：能用来干什么，不能用来干什么

**能：**

1. **验证我们的模型代码与验证协议是对的** —— 同一批数据换切法，R² 从 0.993 掉到 0.84/0.98，这个落差就是我们一直在讲的「切法决定结论」的活证据。
2. **当外部对照**：论文写 R² > 0.99、RPD 3.37；我们在留一浓度下拿到 RPD 7.64（手工特征）——可以写进论文的对照表。
3. **当「传感器做得好」的参照系**：他们同一浓度的重复性 CV 3–20%，我们 20261010 的电极内 CV 中位数 48%。**差距在传感器不在算法。**

**不能：**

1. **不能拿它训练链霉素的模型** —— 分析物、电极化学、响应方向（它信号关闭、我们信号开启）全不同，权重不可迁移。
2. **不能拿它的 0.99 当我们的目标** —— 那是随机切分的数字。它留一浓度也只有 0.84（整条曲线）。
3. **不能证明 sub-LOD 定量** —— 低浓度区留一浓度 R² 0.74 且顺序非单调。

## 7. 复现

```bash
# 1) 拉数据（已放在 /data/workspace/dpv/ext/biosensors-AI-main）
git clone https://github.com/miralab-ai/biosensors-AI

# 2) 三协议对比（P1 论文口径 / P2 留一重复 / P3 留一浓度）
python scripts/validate_external.py --data <repo>/data/lab_measurements --json out.json

# 3) 转成我们自己的 .cor，之后界面里就能直接选 cd36_ngml
python scripts/import_external.py --src <repo>/data/lab_measurements --out data/cd36_ngml

# 4) 命令行跑我们自己的模型
python scripts/ml_models.py --data data/cd36_ngml
```
