# 链霉素传感器 · 下一步实验方案

确认信息：靶标 = 链霉素，**1 µM**；"靶标、无酶" = 有靶标 + 无 Exo III。

---

## 0. 先看清现在站在哪

| 条件 | 比值 I_MB/I_ref | 说明 |
|---|---|---|
| 裸电极 Au@SH-MIL | 1.27 | 电极本底 |
| 材料 + 游离 MB（无 DNA） | 0.57 | 游离 MB 不上电极 |
| 1 µM 链霉素 + H1/H2（无酶） | **2.21** | 有靶标，信号开启 |
| 1 µM 链霉素 + H1/H2 + Exo III | **0.29** | 加酶，信号关闭 |

从 0.57 到 2.21，**全动态范围约 4 倍**。这是个能用但不算宽的量程。

**1 µM 大概率偏高。** 链霉素适配体传感器的文献 LOD 多在 pM–nM 量级，
你现在只测了一个点，无法判断 2.21 是在线性区还是已经饱和。

→ **第一件事不是做校准曲线，是先确认线性区在哪。**

## 1. 阶段 0：动态范围侦察（1 天，9 支电极）

目标：用最少的电极判断"信号从哪开始涨、在哪饱和"。

| 编号 | 链霉素浓度 | 电极数 |
|---|---|---|
| B | 0（空白，无靶标） | 3 |
| C1 | 1 pM | 2 |
| C2 | 1 nM | 2 |
| C3 | 1 µM（已有） | 2 |

判读：

- 如果 C3 ≈ C2 → 1 µM 已饱和，线性区在 1 nM 以下，阶段 1 往下压
- 如果 C1 ≈ B → 1 pM 已低于检出限，阶段 1 往上提
- 如果 B ≈ 0.6 而 C2 已经接近 2.2 → 动态范围只有 1–2 个数量级，需要优化（见 §4）

**这 9 支电极是整个项目信息量最大的一步**，不要跳过。

## 2. 阶段 1：正式校准（2–3 天，24 支电极）

在阶段 0 确定的线性区里，取 6 个浓度，每浓度 3 支独立电极：

```
B(0) ×3, C1 ×3, C2 ×3, C3 ×3, C4 ×3, C5 ×3, C6 ×3   = 21 支
+ 20% QC 损耗 → 实际制备 26 支
```

浓度点按 **半数量级或整数量级等距** 取，例如
0, 10 pM, 100 pM, 1 nM, 10 nM, 100 nM, 1 µM。

要求：

- **每个浓度 ≥3 支独立电极**，不是同一支重复扫
- **至少 2 个批次**（不同日期、最好不同批 MOF），用于检验批次效应
- 每支电极先测 DPV，再测一次重复扫描确认稳定性

## 3. 阶段 2：选择性与真实样品

| 项目 | 内容 |
|---|---|
| 选择性 | 卡那霉素、庆大霉素、四环素、氯霉素，各 10× 浓度 |
| 干扰 | Na⁺, K⁺, Ca²⁺, Cl⁻, 葡萄糖, 尿素 |
| 真实样品 | 牛奶 / 水样加标回收，3 个加标水平 × 3 次 |

## 4. 提高信噪比：最值得做的优化

现在最大的短板是**空白信号太高**。MIL-101(Fe) 带正电、DNA 带负电，
MB 标记的 H1/H2 会**非特异吸附**到 MOF 表面，把空白抬起来。

按性价比排序：

1. **封闭剂**：MCH / BSA / 短链巯基 DNA 封闭 MOF 表面非特异位点
2. **降低 H1/H2 浓度**：探针越少，非特异吸附越少，但特异性组装也变少，需要找平衡
3. **加强洗涤**：PBS 冲洗次数、含 0.05% Tween-20 的洗涤液
4. **缩短 H1/H2 长度**：减少磷酸骨架吸附位点

目标是把空白从 0.57 压到 0.2 以下，动态范围从 4× 提到 10× 以上。

## 5. 测量参数（必须改）

| 参数 | 现在 | 改为 | 原因 |
|---|---|---|---|
| IncE | 0.02 V | **0.005 V** | MB(−0.34) 与 MIL-101(−0.45) 只差 110 mV，20 mV 步进分不开 |
| Amplitude | 0.06 V | **0.025–0.04 V** | 窄化峰宽 |
| PulsePeriod | 0.5 s | 0.2–0.3 s | 补偿点数增加 |

你已经有一条 5 mV 的曲线（`材料10uM.MB-dpv2.cor`，318 点），
在那条上双高斯解卷积是稳定的（MB @ −0.340 V，MOF @ −0.453 V，残差 0.012 µA）。
20 mV 的曲线上解卷积结果会在样本间乱跳，不可用。

## 6. 信号读法：固定电位比找峰更稳

对比三种读法（QC 后，靶标·无酶 vs 靶标·酶）：

| 读法 | 无酶 | 有酶 | 区分度 | 有酶组 CV |
|---|---|---|---|---|
| 宽窗口找峰 (−0.65..−0.15) | 2.21 | 0.30 | 7.3× | 105% |
| 窄窗口找峰 (−0.42..−0.28) | 2.21 | 0.29 | 7.5× | 102% |
| **固定电位 −0.34 V 读数** | 2.21 | **0.23** | **9.4×** | **72%** |

→ 用 **−0.34 V 处的电流值**做 I_MB，比找峰更稳（峰太弱时找峰会跳到 MOF 的肩峰上）。
代码里已改成窄窗口默认，可以切换。

## 7. 分析流程（已就绪）

```bash
# 填好 concentration_M 之后
python ratiometric_calibration.py --meta metadata.csv --data data --out .
```

输出：

- 比值法校准曲线（log-linear 或 4PL 可选）
- **LOD / LOQ**（空白 3σ / 10σ 反算浓度）
- **留一电极** PLS 回归（全程曲线，不是单点）
- QC 自动剔除（I_ref < 1.0 µA）
- `figures/fig9_calibration.png`

元数据只需要这几列：

| 列 | 说明 |
|---|---|
| file | .cor 文件名 |
| electrode | 电极编号（独立重复的单位） |
| concentration_M | 链霉素浓度，空白填 0 |
| batch | 批次（日期/材料批号） |
| condition | signal_on / signal_off |

## 8. 一句话总结

**先把 Exo III 拿掉，用信号开启型做校准；先花 9 支电极搞清楚线性区；扫描步进改成 5 mV；用 −0.34 V 固定电位读数除以 +0.35 V 内参。**
