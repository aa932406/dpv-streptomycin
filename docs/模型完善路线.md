# 怎么把预测模型做完整

> 现状依据：`docs/跨批次分析.md`（195 曲线 / 87 电极 / 15 批次）
> 一句话结论：**模型不缺算法，缺的是实验设计。** 下面按"能交付什么"分五级。

---

## 0. "完整"的验收标准

一个能交付的预测模型，输入一条 DPV 曲线，输出两样东西：**有没有**、**多少**。
它必须同时满足三条，缺一条就不可用：

1. **有浓度梯度** —— 否则"预测出浓度"是编的（现在 0 个 y 值）
2. **换一批还能用** —— 否则模型在背日期（现在留一批次 38%，低于瞎猜）
3. **带不确定度** —— 否则不知道这个数能不能信（现在只有点估计）

现在的状态：三条一条都不满足。所以"完善"不是调算法。

## 1. 五级台阶

| 级别 | 能回答 | 需要的数据 | 电极数 | 时间 | 工具状态 |
|---|---|---|---|---|---|
| **L0 描述性**（现在） | 这批电极一致吗、组间有没有差异 | 已有 | 87 | — | ✅ 已完成 |
| **L1 定性** | 有 / 没有 | 每批**真阴性对照** + 阳性 | 12 | 2 天 | ✅ 面板已有，缺数据 |
| **L2 定量** | 有没有 + 多少浓度 | 6 浓度梯度 + 空白 | 21 | 3–4 天 | ✅ 校准页 + **预测页**已有，缺数据 |
| **L3 当天标定定量** | 同上，且换天仍可用 | 每批 4 支对照 + 未知样同批 | 35 | 2 周 | ✅ 按批标定已上线，缺数据 |
| **L4 跨批通用** | 一台仪器通用 | ≥3 批**同设计** + 域适应 | 84+ | 4 周 | 🟡 PLS/Ridge/SVR/GPR 已上线（预测页 18 行对比），缺域适应 |

### L1 定性（12 支电极，2 天）

```
空白（无靶标 + 有酶）3 支 + 阳性（1 µM + 有酶）3 支，做 2 个批次
```

- 交付：AUC + 置信区间、Youden 截断值、灵敏度/特异度
- 门槛：**每类 ≥4 支电极**，否则 Mann-Whitney 的最小 p 就是 0.20（现在 2v2 只能到 0.33）
- 工具：定性筛查面板已经能做，只要数据表里 `电极` 填对、选对阴性组

### L2 定量（21 支电极，3–4 天）

```
空白 3 支 + 6 个浓度 × 3 支（10 pM / 100 pM / 1 nM / 10 nM / 100 nM / 1 µM）
```

- 交付：校准曲线 R²、LOD、LOQ、线性范围
- 门槛：**≥3 个不同浓度水平**（现在只有 1 个 → 斜率估不出来，脚本会拒绝算）
- 工具：校准与定量页已经能做，含 LOD/LOQ 和逆回归置信区间

### L3 当天标定（35 支电极，2 周）★ 建议目标

```
每批：空白 2 + 阳性 2 + 未知样品 3（未知样品与对照同批测）
共 3–5 批
```

- 交付：**批内 RMSEP + 回收率**，这是唯一能声称"方法可用"的指标
- 为什么是这一级：同批次 AUC 0.73 说明化学效应真实存在；批次偏移（56%）在批内是共模的，
  用当天对照扣掉就行。这是 POCT 设备的常规做法，也是投入产出比最高的一级
- 工具已就绪（2026-10-28）：`fit_calibration_batch` + 界面「按批标定」开关。
  每批自己的截距、斜率能共用就共用、留一批次 RMSE 都直接出（见 `docs/使用说明_Web版.md` 第 7 节）

### L4 跨批通用（84+ 支电极，4 周）

- 交付：留一批次 RMSEP + 预测区间覆盖率
- 门槛：3 个批次必须**同一 protocol**（酶量、孵育、读出窗口一致），否则方向翻转会重演
- 工具已就绪：PLS 全程曲线回归、SVR-RBF、高斯过程不确定度、留一批次验证（预测页 + `ml_models.py`）
- 还缺：域适应（每批中心化 / CORAL）与真实的多批次数据
- **建议先不做**：单实验室做到 L4 的投入产出比很差，L3 已经够写论文

## 2. 模型本身会怎么升级

| 阶段 | 模型 | 为什么 |
|---|---|---|
| L1 | 单特征 + 阈值（或 1 维 LDA） | 1 个变量、几十个样本，复杂模型只会过拟合 |
| L2 | 单特征 + 线性回归 `y = a + b·log C`，并与 SVR-RBF / 高斯过程对比 | 化学计量学标准做法 + 论文里的非线性对照（见 `论文对照_预测模型.md`） |
| L3 | **批内标准化** + 线性/PLS | 见下 |
| L4 | PLS + GPR + 域适应 | PLS 压维（80 → 3 成分），GPR 给区间；跨批时先批内标准化再上模型 |

### 最重要的一步不是换模型，是批内标准化

批次占 56% 方差，而它是**共模**的 —— 同一批所有电极一起漂。
所以最有效的处理是：

```
对每一批：x_norm = (x - 该批对照均值) / 该批对照 SD
```

这一步通常能把跨批次 AUC 从 0.51 拉到 0.7 以上，**比换任何分类器都管用**。
代价是每批必须做对照 —— 这正好和 L3 的设计一致。

### 关于随机森林

之前实测过：80 维原始曲线 + 25 样本，RF 留一扫描 76% 但留一电极只有 56%，
零分布最高能到 52%。**样本少时不要用树模型**，用有约束的线性模型（PLS 压到 3 成分）。
只有到 L4（每类 20+ 电极）才考虑 RF/XGBoost。

## 3. 现在就能做的三件事（不用做新实验）

### ① 在 metadata 里加一列真值标签 ✅ 已上线（2026-10-28）

现在 84 个组名靠正则猜（`label_of`），既脆弱又容易错。建议在 `metadata/metadata.csv` 加：

| 列 | 取值 | 含义 |
|---|---|---|
| `label` | `0` / `1` / 留空 | 0 = 无链霉素，1 = 有链霉素，空 = 不确定/不参与 |
| `role` | `blank` / `standard` / `sample` / `qc` | 这支电极在这次分析里扮演什么 |

有了这两列，所有分析（定性、校准、建模）直接用真值，不再猜组名。
**这是提升可靠性最便宜的一步。**

现在的状态：数据表已经有「批次 / 标签 / 角色」三列，`metadata.csv` 里填了就优先用，
没填才回落到组名正则。`label` 列同时驱动定性筛查的阴性/阳性分组与 `cross_batch.py` 的标签。

### ② 把 material 两组到底加没加链霉素写进去

如果加了 → 20261010 完全没有阴性对照，这批只能做条件筛选；
如果没加 → material+MB 可以当阴性对照（但它没有 H1/H2 探针，严格说不算）。

### ③ 固定一份 protocol 记录

酶量、孵育时间/温度、洗涤次数、读出窗口（`IncE` / `Amplitude`）——
这四项在 15 个批次里各不相同，方向翻转就是这么来的。以后每批照抄同一份。

## 5. 一句话

**补 12 支电极到 L1，补 21 支到 L2，补 35 支（分批）到 L3。**
L3 是建议目标 —— 它能同时回答"有没有"和"多少"，且不要求跨批次通用。
L4 留给以后，且只有当你确定要用同一套 protocol 做满 3 批时才值得投入。
