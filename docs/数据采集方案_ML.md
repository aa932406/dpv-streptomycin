# 机器学习需要多少数据 · 数据采集方案

体系：Au@SH-MIL-101(Fe) / 链霉素 / H1+H2(MB) / 比值法
独立样本单位 = **一支电极**（同一支电极重复扫 = 伪重复，不能算 n）

---

## 1. 先说清楚：这个体系里 ML 不是目的

单分析物 + 比值法 + 干净响应，最优模型是**校准曲线**（2 个参数：a + b·log C）。
把它叫"机器学习"不会让它变好。

ML 真正能加分的地方只有三个：

| 场景 | 方法 | 为什么需要 ML |
|---|---|---|
| **批次迁移** | 域适应 / 迁移学习 | 电极批间差异大（I_ref 波动 7 倍），用曲线形状预测并校正批次偏移 |
| **多目标识别** | 多标签分类 / PLS2 | 一条曲线同时读出链霉素 + 卡那霉素 + 庆大霉素 |
| **不确定度量化** | 高斯过程回归 GPR | 每个样品给出置信区间，自动标记不可靠测量 |
| **全程曲线回归** | PLS / Ridge | 峰重叠、基线漂移时，用 80–320 维曲线比用单峰更稳 |

前两个是论文级卖点，后两个是工程改进。**只做单分析物定量，用不着深度学习。**

## 2. 为什么 n=9 不够

![样本量](fig10_sample_size.png)

留一电极交叉验证在 n=9 时得到的 76%，95% 置信区间是 **[47%, 95%]** —— 宽度 47 个百分点。
换句话说，你现在的准确率数字**基本没有信息量**。

要让准确率的精度达到 ±5 个百分点：

| 目标准确率 | 需要的 n |
|---|---|
| 0.70 | 84 |
| 0.80 | 64 |
| 0.90 | 36 |

回归误差（RMSEP）也一样：n=9 时你估出来的 RMSEP 本身有 **±24%** 的不确定度，n=60 才降到 ±9%。

## 3. 三档数据预算

| 档 | 独立电极 | 曲线数 | 能交付什么 | 工时估算 |
|---|---|---|---|---|
| **A 最低可发表** | **30** | 30–45 | 校准曲线 + LOD/LOQ + 动态范围 | 3–5 天 |
| **B 化学计量学** | **60** | 60–120 | A + 全程曲线 PLS + 留一电极/留一批次验证 | 1.5–2 周 |
| **C 真正的 ML** | **150+** | 150–300 | B + 批次迁移 + 不确定度量化 +（可选）多目标 | 3–4 周 |

> 工时按每天能完成 8–12 支电极估算，按你的实际产率折算。

**如果要投分析化学类期刊，A 档就够；如果论文里想写"机器学习"，B 档是底线，C 档才有说服力。**

## 4. A 档具体怎么采（30 支电极）

| 组 | 链霉素浓度 | 电极数 | 用途 |
|---|---|---|---|
| 空白 | 0 | 5 | 算 LOD 的 3σ |
| C1 | 10 pM | 4 | 线性区下界 |
| C2 | 100 pM | 4 | |
| C3 | 1 nM | 4 | |
| C4 | 10 nM | 4 | |
| C5 | 100 nM | 4 | |
| C6 | 1 µM | 5 | 线性区上界（确认饱和） |

浓度点按整数量级排，等摸清线性区后再加密。

## 5. B 档：加批次维度（60 支电极）

```
3 个批次 × 5 个浓度 × 4 支电极 = 60 支
```

三个批次必须是**不同日期、最好不同批 MOF 合成**。
这样才能做**留一批次交叉验证**（用 2 个批次训练、第 3 个批次测试）——
这是证明模型能"迁移"的唯一方式，也是 ML 部分最有说服力的实验。

## 6. C 档：加分析物维度（150+）

```
5 种分析物（链霉素、卡那霉素、庆大霉素、四环素、氯霉素）
× 4 个浓度 × 6 支电极 = 120 支
+ 20 支空白 / 混合样品
```

这样才能做多目标识别。

## 7. 元数据必须记这些列

ML 的效果**一半取决于元数据记不记全**。建议表头：

| 列 | 必填 | 说明 |
|---|---|---|
| file | ✓ | .cor 文件名 |
| electrode | ✓ | 电极编号，**独立样本的唯一标识** |
| concentration_M | ✓ | 链霉素浓度，空白填 0 |
| batch | ✓ | 批次（日期 + MOF 批号） |
| condition | ✓ | signal_on / signal_off |
| analyte | ✓ | streptomycin / kanamycin / ... |
| replicate | ✓ | 同浓度同电极内的扫描序号 |
| ref_current_uA | ✓ | I_ref，QC 用 |
| incE / amplitude | ✓ | 扫描参数（改参数后必须区分） |
| pH | 建议 | 缓冲液 pH |
| moz_lot | 建议 | MOF 合成批号 |
| blocking | 建议 | 封闭剂（MCH/BSA/无） |
| operator | 建议 | 操作者 |

后面三个"建议"列，在你做批次迁移的时候会变成**关键协变量**。
