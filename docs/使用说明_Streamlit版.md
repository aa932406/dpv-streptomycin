# Web 版使用说明（傻瓜式界面）

面向"我有一批 .cor，想知道有没有链霉素、有多少"的场景。所有统计和建模都在后台自动跑，界面上只留需要你填的东西。

## 1. 启动

双击项目根目录的 **`run_web.bat`**。

- 第一次运行会建 `.venv` 并装依赖（numpy / scipy / pandas / scikit-learn / matplotlib / streamlit），
  需要几分钟，之后启动只要几秒。
- 装完浏览器会自动打开 <http://localhost:8501>。没自动开就手动点这个地址。
- 关掉那个黑窗口（或按 Ctrl+C）就停止服务。

端口被占用时改用别的端口：

```bash
.venv\Scripts\python.exe -m streamlit run scripts\app.py --server.port 8502
```

## 2. 侧栏：数据从哪来

| 选项 | 说明 |
|---|---|
| **使用本地 data/ 文件夹** | 下拉框列出 `data/` 下所有日期文件夹，选一个即可。新数据放 `data/20261105/` 就会自动出现在列表里 |
| **上传 .cor 文件** | 拖一批文件进去，适合临时看别人的数据。上传的数据不落盘 |

下面的「分析参数」（默认值基本不用动）：

- **基线阶数** 4：扣背景用的多项式阶数。曲线抖得厉害调到 5，扣得太狠调到 3。
- **内参峰 QC 下限** 35%：`+0.35 V` 那个 MIL-101(Fe) 峰小于「本批内参中位数 × 35%」就判这条曲线不可靠。
  用**相对值**而不是固定的微安数，是因为内参峰本身在批次之间差 2-7 倍（同一支电极在不同批次
  可以是 0.5 µA 也可以是 3.3 µA）—— 固定 1.0 µA 的门槛在有的文件夹里一条不剔，在另一个里全剔。
  界面会写明这次的绝对门槛是多少（例如「本批内参中位数 2.04 µA × 35% = 0.71 µA，23 / 25 条通过」）。
- **响应指标** `I_MB / I_ref`：比值法，抵消电极面积差异。也可以换成裸的 `I_MB`。
- **只用 QC 合格曲线**：勾上则不合格的曲线不进统计和建模。

> 换了日期文件夹之后，这两项会**自动让步**：老数据的扫描窗口（0.6→-0.6、0.19→-0.20 等）
> 常常盖不到 -0.34 V 的 MB 峰或 +0.35 V 的内参峰。这时界面会提示一句，
> 自动把响应指标换成能读的那个（阴极峰高 / 阳极峰高 / 总电荷 Q），
> 没有内参峰时内参 QC 也会自动跳过，不会再把整批曲线判成「不合格」。

侧栏最下面「生成演示数据」按钮会造一批**合成**数据（写在 `data/demo/`），
用来熟悉界面。演示数据顶部有粉色横幅提示，**不能写进论文**。

## 3. 数据表：唯一需要你动手的地方

打开一个日期文件夹时，程序会**自动去找 `metadata.csv`** 把浓度和分组填进表格，顺序是：

1. `data/<日期>/metadata.csv`（和 .cor 放在一起的那份，优先）
2. `metadata/metadata.csv`（项目级的统一表）

表格上方会写明这次用的是哪一份（比如「浓度和分组来自 metadata/metadata.csv」）。
两份都没有、或者那一列是空的，表格就是空的 —— 直接在界面上改也一样生效，
界面上的改动不会写回 csv。

表格里的列：

| 列 | 能不能改 | 怎么填 |
|---|---|---|
| 文件 | 锁死 | — |
| 分组 | 下拉 | 自动从文件名推出来，可以改 |
| **浓度数值** | **改这里** | 这支电极的链霉素浓度。文本框，可以直接写 1e-6；空着就是未知样品 |
| 单位 | 下拉 | pM / nM / µM / mM / M，默认 nM |
| 电极 | 锁死 | 同一支电极重复扫描必须同名 |
| QC | 锁死 | ✓ 内参峰够大，参与分析；✗ 电极制备不良，已剔除 |
| 批次 | 可改 | 同一天做的电极填同一个批次名。不填就用文件夹名兜底（一个 `data/<日期>/` 就是一批） |
| 标签 | 可改 | `1` = 有链霉素，`0` = 无链霉素（阴性对照），留空 = 不知道。填了就不用靠组名猜 |
| 角色 | 锁死 | blank / standard / sample，从 metadata.csv 的 `role` 列来 |

浓度的三种含义（不用另设一列）：

- **留空** = 未知样品 → 「结论」页会给出"检出/未检出 + 浓度"
- **0** = 空白对照 → LOD 靠它算，至少 3 支
- **> 0** = 标准点 → 校准曲线靠它

> **单位是相乘关系**：填 `1e-6` 且单位选 `M` = 1 µM；填 `1e-6` 但单位还是默认的 `nM`
> = 1e-15 M（差了 10 亿倍）。表格下方会实时显示「标准点 N 支（K 个不同浓度：… M）」，
> 填完扫一眼那个数字对不对。最小浓度算出小于 1e-14 M 时界面会黄字提醒你查单位。

> 电极名很重要：`xxx_ReStart` 是同一支电极的重复扫描，必须和 `xxx` 是**同一个电极名**。
> 界面上已经自动处理了；如果你手动改，别把它们当成两支独立电极 —— 否则交叉验证准确率会虚高十几个点。

## 4. 六个页签

| 页签 | 内容 |
|---|---|
| **结论** | 每个未知样品一张卡片：检出 / 未检出 / 无法判定 + 浓度 + 95% 置信区间。**这是给外行看的那一页** |
| 曲线 | 基线校正后的全部曲线、各组均值±SD、`I_MB vs I_ref` 散点、单条曲线的原始/校正对照 |
| 统计 | 各组汇总（n / mean / sd / CV%）、单因素 ANOVA（F / p / η² / Kruskal）、Tukey HSD 两两比较、箱线图 |
| 校准与定量 | R²、斜率、LOD、LOQ；校准线 + 残差图；未知样品预测表；单样品读数图 |
| 建模 | 输入（整条曲线 / 16 个手工特征）× 算法（LDA / 随机森林），留一电极交叉验证 + 混淆矩阵 + 置换检验 |
| 导出 | 一键打包 zip：HTML + Word 报告、全部图 PNG、全部表 CSV、原始 .cor |

## 5. 什么时候才能给出浓度

「结论」页会直接告诉你缺什么。硬门槛：

| 项目 | 最低要求 | 为什么 |
|---|---|---|
| 空白对照 | ≥ 3 支 0 浓度 | 没有空白的 3σ 就算不出 LOD |
| 浓度梯度 | ≥ 3 个不同浓度（建议 6 个跨 3 个数量级） | 少于 3 个点斜率没有意义 |
| 标准点总数 | ≥ 4 支 | 少于 4 支自由度不够 |
| 独立电极 | ≥ 6 支（30 支以上才谈得上模型） | 否则任何准确率的置信区间都比效应本身宽 |

现在的 2026-10-10 数据只有 **1 个浓度（1 µM）**，所以「结论」页会显示
"现在还答不了多少浓度"，这是正确行为，不是 bug。

## 6. 没有浓度梯度时：定性筛查

如果整批数据只有一个浓度（比如都是 1 µM），「结论」页上半部分会告诉你算不出浓度，
**下半部分会自动给出定性筛查面板** —— 这是这批数据真正能回答的问题：**有没有**。

怎么用：

1. 「阴性对照」选不含链霉素的那一组（默认按组名猜，可以改）；
2. 「阳性样品」选含链霉素的那一组（默认选带酶的完整体系）；
3. 「截断值 = 空白均值 ± k×SD」默认 3，想放宽就调小。

它会算出四个数：**信号比**、**电极级 p 值**、**效应量 d**、**留一电极判别准确率**，
然后用截断值给每个未知样品判「检出（定性）」/「未检出（定性）」。

三种情况要会读：

| 界面提示 | 意思 | 怎么办 |
|---|---|---|
| 「即使两组完全分开，Mann-Whitney 的最小 p 也只能到 0.33」 | 电极数太少，统计检验根本使不上劲 | 看信号比和效应量；要 p<0.05 每组至少 4 支电极 |
| 红框「这条截断值切不开两组」 | 空白的波动和两组之间的差一样大 | 先降噪（封闭 / 降探针浓度 / Tween-20 洗涤），不是程序问题 |
| 「两组在统计上分不开（p > 0.05）」 | 这个指标判不出检出 | 换响应指标，或先解决信噪比 |

> 定性筛查永远给不出浓度。它只回答「有没有」，而且是在「阴性对照选得对」的前提下。
> 最理想的阴性对照是**同基质、同酶量、只是不加链霉素**的那一组 —— 现在这批数据里没有。

## 7. 多个批次一起分析：按批标定

数据表里出现 2 个以上不同的「批次」时（把几天的数据合进一个文件夹，或 metadata 里填了不同的 batch），
表格下方会多出一个勾选框：

**按批标定：每批用自己那天的标准点定截距**

勾上之后：

- 每一批用**自己那批**的标准点拟合一条线（每批浓度都够就各批各拟合，不够就共用斜率、各批自己的截距）；
- 未知样品用**它所属批次**的截距反算浓度，「结论」页的卡片标题会带上是哪一批；
- 「校准与定量」页顶部多出一块「按批标定」：每批的截距 a / 斜率 b / R² / LOD / LOQ，以及逐样品的预测表。

为什么需要它：跨批次分析（见 `docs/跨批次分析.md`）测出来 **56% 的方差在批次之间**。
把所有批次当成一条线时 R² 会明显掉下去（演示数据：按批 0.971 → 合并 0.550）。
批次偏移是**共模**的，所以用当天的标准点就能扣掉；斜率能不能共用要看你自己数据 —— 程序会自己选。

三个要看的数字：

| 数字 | 含义 |
|---|---|
| 合并 R² | 按批标定之后的整体拟合质量 |
| 全局单线 R² | 把所有批次当成一条线时的质量。两者差多少 = 批次偏移吃掉了多少 |
| 留一批次 RMSE | 模拟「今天没做标定，斜率借别的批次、截距用自己批次的」，单位 dex（0.3 dex ≈ 浓度差 2 倍） |

> **各批 LOD 会差很多倍**（演示数据差 115 倍），这不是 bug：LOD 由空白 SD 与斜率算出来，
> 两者每批都不同。所以每批都得有自己的空白，不能借用别的批次的 LOD。

## 8. 建模页怎么读

- **留一电极交叉验证**：同一支电极的多次扫描强制分在同一折。这才是诚实的数字。
  留一扫描（把每次扫描当独立样本）会虚高十几个点，别用那个。
- **置换检验**按钮：把标签在电极之间随机打乱 200 次，看真实准确率能不能超过打乱后的 95 分位。
  超不过就是过拟合 —— 界面会红字警告你。

## 9. 常见问题

**Q：上传了一堆文件，提示"这些文件里没有解析出任何数据"**
A：文件不是本项目已验证的科斯特 CorrTest CS350H `.cor` 文本格式。用记事本打开样例，开头应包含 `CORRW ASCII`、`CorrTest for Windows`，DPV 文件类型行为 `ID_DiffPulseVA`。其他品牌/型号暂未验证。

**Q：QC 把所有曲线都剔掉了**
A：内参峰普遍太小。现在门槛是「本批内参中位数 × 35%」，一般不会全剔；真出现说明这一批的
内参峰整体很弱（电极没做好 / 材料批次有问题）。把侧栏比例调低（比如 15%），或取消勾选「只用 QC 合格曲线」。

**Q：批次列要填吗？**
A：想跨天分析就必须填。不填时程序用文件夹名兜底（一个 `data/<日期>/` = 一批），
同一天的数据合在一个文件夹里分析就不用手动填。想把几天合起来做「按批标定」，
要么把它们放进同一个文件夹并在表里把批次改对，要么直接在「上传 .cor 文件」里一起拖进去再填批次。

**Q：标签列填了有什么用？**
A：填 `1` / `0` 之后，定性筛查和建模用的是**你给的标签**，不再靠组名正则去猜。
组名起得随意（比如 `G1` / `G2`）时特别有用 —— 之前只能从名字里找「有靶标/无靶标」。

**Q：中文显示成方块**
A：界面中文由浏览器渲染，正常不会出问题。图里的文字是英文的（容器里没有中文字体），
这是刻意的 —— 免得在你机器上变豆腐块。

**Q：我明明在 metadata.csv 里填了浓度，「结论」页还是说缺标准点**
A：先看「结论」页黄框里那句话到底是哪一种，它现在会分开说：

- 「一个浓度都没读到」→ 文件没被读到。确认文件叫 `metadata/metadata.csv`，
  第一行有 `file` 和 `concentration_M` 两列，`file` 列写的是 .cor 的文件名（不是完整路径）。
- 「填的都是同一个值 —— 现在填的全是 1.00e-06 M」→ 浓度读到了，但只有一个浓度。
  校准曲线要的是**一串不同浓度**：至少 3 个不同浓度、每个浓度 3 支电极、外加 ≥3 支空白。
  只有 1 个浓度时，斜率根本不存在，这不是 bug。
- 「最小浓度算出来是 1e-15 M」→ 单位选错了，见上面第 3 节的说明。

**Q：提示某个 .cor「scanned over …V, which does not cover …V」被排除**
A：这个文件扫描的电位范围和同批其他文件不一样。现在程序会先按方法筛一遍：
同一个文件夹里混进 CV / SWV / 计时电流时，只有 DPV 进入分析（CV 没有脉冲峰，
本来就不该和 DPV 一起比）。剩下的文件再按电位窗口筛，差一点点（半个步长以内）不算不覆盖。

**Q：浓度填了，为什么 12 个材料样品变成「待测」**
A：`material` / `material+MB` 这两组没有加链霉素，浓度列留空 = 未知样品。
它们其实是**材料本底对照**，不是标准点也不是空白（基质里没有 DNA 探针，
当空白会把空白的 3σ 算偏）。想让它们当空白就填 0。

**Q：改了数据表但数字没变**
A：Streamlit 每次交互都会重跑，表格改完按回车/点空白处就会刷新。如果没刷新，按 F5。

**Q：顶部提示「13 个文件没参与分析」**
A：这批文件扫描的电位范围和其他文件不一样（比如溶出法 SWV 和 DPV 混在一个文件夹里）。
一个批次只能放在同一条电位轴上比，范围不同的会被排除，展开那个折叠框能看到每个文件的原因。

**Q：建模页准确率 0%，是不是坏了**
A：不是。分组太多、每支电极的曲线太少时（比如 14 组 / 16 支电极），分类器本来就学不到东西。
界面会直接告诉你「和瞎猜没区别，别拿这个下结论」。
真正能做分类至少要 2-3 个分组、每组 ≥5 支独立电极。

**Q：老文件夹打开后响应指标自己变了**
A：那是自动保护。扫描窗口没覆盖 MB 峰（-0.34 V）或内参峰（+0.35 V）时，
读出来的「峰高」其实是窗口边缘的假峰。界面会说明换成了哪个指标。
