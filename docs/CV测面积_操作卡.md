# CV 测电极有效面积 · 操作卡

> 目的：把「µA」换算成「µA·cm⁻²」。论文里的灵敏度都要带面积，猜一个数去算，正是不同论文对不上的原因。
> 一支电极 4 个扫速，约 40 分钟（含配液）。

---

## 0. 先准备溶液

**1 mM 铁氰化钾 K₃[Fe(CN)₆] + 0.1 M KCl，配 20 mL，现配现用，避光，当天用完。**

| 试剂 | 分子量 | 20 mL 需要 |
|---|---|---|
| K₃[Fe(CN)₆] | 329.24 | 6.6 mg |
| KCl | 74.55 | 149 mg |

用去离子水（不是自来水，不是纯水机刚接的前 200 mL）。摇匀到完全溶解，溶液应是淡黄色透明。

---

## 1. 电极预处理（3 分钟）

1. 去离子水冲洗工作电极表面，氮气吹干或用滤纸**吸**干（不要擦，会留纤维）。
2. **用一支没修饰过的裸碳电极测**。面积是电极本身的属性；已经滴了 Au@SH-MIL-101(Fe) 的电极测出来是膜的面积，不是电极的面积。
3. 三支电极插入 10 mL 溶液，工作电极圆盘必须完全浸没，参比电极里不能有气泡。

---

## 2. CHI 参数（CV 模式）

| 参数 | 值 | 说明 |
|---|---|---|
| 起始电位 | −0.2 V | 铁氰化钾在碳电极上氧化峰约 +0.25 V |
| 最高电位 | +0.6 V | |
| 最低电位 | −0.2 V | |
| 扫速 | 20 / 50 / 100 / 200 mV/s | 分 4 次跑，每次改扫速 |
| 圈数 | 3 | 取第 2–3 圈 |
| 静置时间 | 5 s | |
| 灵敏度 | 1e-5 A/V 或自动量程 | 峰电流约 5–30 µA |

> CorrTest 界面上若没有「起始电位」，就设 **StepVolt1 = −0.2、StepVolt2 = 0.6、Cycles = 3**，扫速填 ScanRate。

---

## 3. 每个扫速存一个文件

命名 `CV_020.cor` / `CV_050.cor` / `CV_100.cor` / `CV_200.cor`，
全部放进 **`data/<今天日期>/`**（例如 `data/20261028/`）。

扫速是程序从文件头的 `ScanRate` 读的，文件名只是为了你自己看着方便。

---

## 4. 怎么判断这次测成功了

| 检查 | 合格 | 不合格怎么办 |
|---|---|---|
| 有一对峰 | 氧化峰 +0.2~+0.3 V，还原峰 +0.1~+0.2 V | 没峰 → 浓度提到 5 mM；窗口扩到 −0.3~+0.8 V |
| ΔEp（两峰电位差） | 60–120 mV | > 200 mV → 电极接触不良 / 表面脏，换电极或抛光 |
| 峰电流随扫速增长 | 200 mV/s ≈ 20 mV/s 的 3.2 倍（√10） | 不成比例 → 吸附控制，电极表面有膜 |
| 第 2、3 圈 | 基本重合 | 差很多 → 溶液没静置够，或电极在动 |

---

## 5. 出结果（1 分钟）

1. 双击 `run_web.bat`，浏览器打开界面。
2. 顶部文件夹选今天那个（例如 `20261028`）。
3. 底部导航 → **导出** → 第二张卡「工作电极有效面积（CV 法）」。
4. 卡里会自动列出本文件夹的 CV 文件和读到的峰电流（扫速 / 阳极峰 / 阴极峰 / ΔEp）。
5. 点 **「填入下面的表」** → 点 **「算面积」**。
6. 得到有效面积 + R² + 斜率。点 **「保存为电极面积」**，上面那张文献表的灵敏度会自动带上 cm⁻²。

**怎么读数**：3 mm 圆盘几何面积 0.0707 cm²，丝网印刷碳电极实测一般在 **0.05–0.12 cm²**。
算出 0.02 或 0.5，先查三件事：探针浓度是不是填成 M 而不是 mM、扫速是不是 mV/s、读的是不是背景而不是峰。

---

## 6. 常见问题

**没有峰 / 峰很小**
浓度太低（1 mM 是下限，可提到 5 mM）；电位窗没覆盖；参比电极干涸或进气泡；电极表面有旧膜。

**四个点不在一条直线上（R² < 0.98）**
看界面上的残差表，找出偏离最大的那个扫速重测。常见原因是高扫速下峰电流读到了电容电流。

**峰电流随 v 线性而不是 √v**
吸附控制，说明电极表面被膜占住了。这个电极不适合用 Randles–Ševčík 算面积，换新电极。

**面积每次测都不一样**
正常波动 ±10%。差一倍以上说明电极批次不同或溶液配错，重配溶液再测。

## 7. 命令行等价（不想开界面时）

```bash
# 直接读 4 个 CV 文件的峰电流
python scripts/cv_peaks.py --data data/20261028

# 手填峰电流算面积
python scripts/area_calc.py --conc 1 --v 20,50,100,200 --ip 7.49,11.78,16.62,23.48 --save
```

> 想先看看这条链路长什么样：界面里把文件夹切到 `demo_cv`（4 条合成的 CV，真实面积 0.0707 cm²），
> 点两下应该得到 0.0705 cm²。合成数据是照 Randles–Ševčík 造的，用来验证工具本身，不是你的电极。
