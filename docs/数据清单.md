## 各文件夹现在能做什么

| 能做 | 条件 |
|---|---|
| 看曲线、分组均值±SD、PCA、ANOVA + Tukey | 有 ≥2 个分组、每组 ≥2 条曲线 |
| 建模（LDA / 随机森林 + 留一电极） | 有 ≥2 个分组、≥2 支独立电极；分组越碎结果越没意义 |
| 算浓度、LOD、LOQ | **目前一个文件夹都不够**：需要 ≥3 个浓度梯度 + ≥3 支空白 + ≥4 个标准点 |
