## 3. 这次跑出来、并修掉的三个真问题

### 3.1 无表头的 .cor 被脚本路径丢掉（20260625 少 2 条、20260627 少 2 条）

`data/20260625/` 里有两条 CHI 导出**完全没有表头**（第一行直接就是 `-5.00E-01\t7.74331E-06`）。
解析器上一轮已能读它们，但脚本路径仍按 `technique == "DPV"` 过滤，而这两条因为没有表头
只能记成 `plain` → 被当成"别的技术"排除。

修法（`scripts/dpv_pipeline.py`）：选片时做别名归一 `TECH_ALIAS = {"plain": "DPV"}`。

- 20260625：13 → **15** 条曲线
- 20260627：29 → **31** 条曲线

现在两条路径的数字完全一致。

### 3.2 `data/demo` 跑 CLI 直接崩

```
ValueError: The number of samples must be more than the number of classes.
```

崩在画 LDA 判别空间那一步：演示数据的条件数 ≥ 曲线数，LDA 拒绝拟合，
而那段代码没有 try/except，**整个脚本直接退出**（前面算好的图全白跑）。
真实数据因为条件少没触发，属于潜伏 bug。

修法：加 `len(y) > len(labels)` 前置判断 + try/except，失败只跳过这张图。

### 3.3 准确率被"最大的那一类"骗了（口径问题，比 bug 更严重）

演示数据 `demo` 的分组是 空白 3 支 / 标准点 18 支 / 未知样 2 支。
原来的「准确率」算出来 **65.2%**，看着不错 —— 但模型其实**几乎只会回答"标准点"**：

- 原始准确率 65.2%（因为 18/23 就是标准点，全答标准点也有 78%）
- **平衡准确率 27.8%**（三类各自召回率的平均）→ 比瞎猜的 33.3% 还低

也就是说：这个 65% 什么也没证明。改用**平衡准确率**作为主指标（置换检验也改用同一个量），
界面同时列出两个数字，并说明差别。

## 4. 三件必须说清楚的事

### 4.1 14 个文件夹的「0%」是数学必然，不是模型差

留一电极交叉验证的做法是：拿出 1 支电极做测试集，用其余电极训练。
如果**每个条件只有 1 支电极**，那么被拿出的那支电极代表的类别在训练集里根本不存在 ——
模型没有任何机会答对，准确率必然是 0%。

表里 15 个真实文件夹中，**14 个都是每条件 1 支电极**（20260927 有 2 个条件做到 2 支）。
只有 **20261010 是 2–3 支/条件**，所以也只有它给出了有意义的判别力：
平衡准确率 59.5%，置换检验 p = 0.0099。

界面建模页现在会直接说明这一点，不再只丢一个 0% 出来。

### 4.2 没有任何文件夹有浓度梯度 → 全部算不出浓度

15 个真实文件夹里，能填 `concentration_M` 的只有 20261010 的 13 条（都是 1 µM）。
单一浓度画不出校准线（需要 ≥3 个浓度、≥4 个标准点），所以「多少浓度」这一问
目前**一个文件夹都答不了**。这不是工具的问题，是实验设计里还没有浓度梯度。

### 4.3 能做的只有「有没有」，而且只有一批站得住

- 20261010：LDA 留一电极 **59.5%（平衡）/ 60.0%（原始）**，置换 p = 0.0099 → 判别力真实存在
- 定性筛查（material 2 支 vs target+Enz 2 支）：信号比 0.24×，p = 0.333，**截断值切不开两组**
  （空白 CV 45%，3σ 阈值落到负值）→ 先把空白噪声压到 CV 15–25% 再谈阈值
- 其余文件夹：条件数太多、每条件 1 支电极，统计与判别都不成立

## 5. 下一步（按性价比排）

1. **把空白压干净**：MCH/BSA 封闭、降 H1/H2 浓度、洗涤加 0.05% Tween-20。空白 CV 从 45% → 20% 以下，3σ 阈值才有意义。
2. **补浓度梯度**：一天做 3 个浓度 × 3 支电极 = 9 支（0 / 10 nM / 1 µM），就能出校准曲线与 LOD。
3. **每个条件 ≥2 支电极**（3 支更稳）：这是让「留一电极」从数学上成立的最低要求。
4. **同一批里同时有阳性与阴性**：否则批次与标签绑死，留一批次验证会掉到 38%（已实测）。

## 6. 复现方式

```bash
# 全部文件夹跑脚本路径
for d in data/*/; do python scripts/dpv_pipeline.py --data "$d" --out "out/$(basename $d)"; done

# 单个文件夹跑界面路径（需要后端已启动）
curl "http://127.0.0.1:8000/api/analyse?folder=20261010"
```

原始数据（`out/sweep.json`）保留了上表每一行的完整字段，包括 ANOVA 最佳指标、
留一电极混淆矩阵输入、定性筛查结果。
