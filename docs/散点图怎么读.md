# 散点图怎么读

这个工具里有三张散点图，每一张都容易被读错。共同前提只有一句：

> **一个点 = 一条 DPV 曲线**，不是一次扫描里的很多个电位点，也不是一次实验里的多次重复。

---

## 一、MB 峰电流 vs 内参峰电流（曲线页）

横轴：内参峰 I_ref（Au@SH-MIL-101(Fe) 的 Fe(III)/Fe(II)，+0.35 V）
纵轴：MB 峰 I_MB（−0.34 V）
双对数坐标；灰色实线是 I_MB = I_ref，虚线是 0.25 / 0.5 / 2 / 4 倍的等比值线。

**为什么要这么画。** 电极面积、涂膜厚度、每片电极的个体差异会**同时**抬高或压低两个峰。
只看 I_MB，你分不清"MB 真的变多了"还是"这支电极本来就电流大"。
把两个峰放在同一张图上，这种整体漂移会沿着对角线滑动，**不改变点相对对角线的位置**。
真正有意义的移动是**离开对角线**：

- 点在角平分线**上方** → MB 相对内参偏高 → 信号"开"
- 点在角平分线**下方** → MB 相对内参偏低 → 信号"关"

**20261010 这批的实际情况（25 条曲线）：**

| 组 | 点落在哪 | 读法 |
|---|---|---|
| target_noEnz（红） | 对角线**上方**，I_MB 4–5 µA，I_ref 只有 1.2–1.6 | MB 大量富集在电极上，信号最强 |
| material（蓝） | 对角线附近偏上 | 有一定 MB 本底 |
| material+MB（绿） | 对角线**下方** | 游离 MB 反而贴不上电极 |
| target+Enz（紫） | 对角线**下方很远**，I_MB 只有 0.3–0.5 µA | 酶切后信号几乎归零 |

这张图一眼就说明了当前实验的核心矛盾：**加了 Exo III 之后信号不是变强而是掉下去 7–9 倍**，
而按"释放 MB → 信号升高"的设计它应该往**右上**跑，实际却往**右下**跑了。

**读这张图的四条规矩：**

1. 点挤在一小团 = 重复性好；散得很开 = 组内差异大于组间差异，这时比组均值没有意义。
2. 点沿着对角线滑动，多半是电极面积/涂膜厚度的差别，不是化学响应变了。
3. 两个点完全重合，或者贴在图的边界上 = 某条曲线的峰没读到（窗口没覆盖、峰太小），去「数据」页看 QC。
4. 这张图**不给浓度**，只给"信号开/关"的相对强弱。

## 二、PCA 得分图（统计页）

横轴 PC1、纵轴 PC2，括号里的百分比是这两个方向各解释了多少总差异。

PCA 做的事：把每条曲线（80–220 个电位点）压缩成两个坐标，让**差异最大的方向**排在前面。

**怎么读：**

- 两组**分开** → 曲线形状确实不同，条件有区分度
- 两组**叠在一起** → 曲线几乎一样，任何分类器都分不开
- PC1 占 50% 以上 → 有一个因素主导了全部差异（通常是"有没有加酶"这种大头）

**20261010 的实际结果：** PC1 46.9%、PC2 35.9%。target_noEnz 被拉到 PC1 的负端，
target+Enz 聚在正端，而 **material 与 material+MB 在中间完全重叠** ——
也就是说 DPV 曲线分不开"只泡了材料"和"泡了材料再泡 MB"这两个条件。

**三个常见误读：**

1. PC1 不是浓度，也不是信号强度，它只是"差异最大的那个方向"。想知道 PC1 代表什么，需要载荷图，本页没画。
2. 点少（每组 2–3 个）时 PCA 很容易画出"看起来分开了"的假象，换一条曲线位置就变。
3. 分开 ≠ 能定量。分开只说明形状不同，能不能读数要看校准页。

## 三、真值 vs 预测（预测页，只有填了浓度梯度才出现）

横轴是这个标准点**已知**的浓度，纵轴是模型**只看曲线**猜出来的浓度，双对数坐标。
灰色虚线是理想线。

**怎么读：**

- 点贴近虚线 → 猜得准
- 点整体在虚线上方 → 模型系统性高估；在下方 → 系统性低估
- 点沿虚线随机散开 → 随机误差，可以靠多测取平均压下去
- 点偏离虚线形成一条斜带或弧形 → 系统偏差（校准线选错，或超出线性范围）

这张图上的点全部来自**留一电极**的预测 —— 模型没见过这支电极，
所以它代表"换一支新电极还能猜多准"，而不是"拟合得多好"。

**当前状态：** 你的数据只有一个浓度（1 µM），这张图不会出现。
要让它出现，最少要做 3 个浓度 × 3 支电极 = 9 支（空白 3 + 10 nM 3 + 1 µM 3），一天可完成。

## 四、一句话总结

| 你想回答的问题 | 看哪张图 | 看什么 |
|---|---|---|
| 加了酶以后信号是升还是降 | MB vs 内参散点 | 点在角平分线上方还是下方 |
| 两个条件能不能分开 | PCA 得分图 | 两团点有没有重叠 |
| 模型准不准 | 真值 vs 预测 | 点离虚线多远（还要看 RPD） |
| 某条曲线是不是坏数据 | 曲线页数据表 QC 列 | 剔除的那几条不要拿去算均值 |
